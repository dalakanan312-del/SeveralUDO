HOW THIS FIRST SIMS 3 EDITION WORKS

Reliable clock alignment, without touching your save

Sims 3 uses a different package-based mod system than Sims 4. This release provides the tracker-side receiver and a local relay that works with Sims 3. Until a compiled Sims 3 .package reporter is released, it deliberately uses a small manual reporter: read the game’s current day and time, enter them once, and the relay delivers the queued report.

  1. Download and extract the private kit.
  2. Run Install or Update SeveralUDO Sims 3 Clock Sync.bat.
  3. Run the included self-test, then start the relay.
  4. When you want to align the tracker, run Report Sims 3 Clock Now.bat and enter the day and time displayed in-game.
  5. On the first report, give the game save a stable name. Use the same name for that save afterward.
Current scope: the Sims 3 kit safely advances the tracker clock and protects the save pairing. It does not yet claim to automatically read Sims, pregnancy, health, portraits, or other Sims 4-only telemetry.

Sims 4 Clock Sync remains its own .ts4script kit. A Sims 3 private link will reject a Sims 4 report, and vice versa, before any tracker data changes.
