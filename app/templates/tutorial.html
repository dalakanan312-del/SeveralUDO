01

TEN-MINUTE SETUP

Create your chronicle

1

Create or select a save

Open Saves & Backups. Create a save for one challenge, or choose an existing save from the sidebar. Give it a name based on the founding household, such as Cooley Decades.

2

Set the historical calendar

Enter the challenge’s starting year, current Global Day and days per historical year. These values convert every birth, marriage, death and event into a historical date. Set the challenge location so event and planting rules can choose the correct region.

3

Add the founding household

Open Households, add the home, and record its name, location, class and notes. Households make event eligibility, rotation planning and family summaries more accurate.

4

Add the first Sims

Open Sims and add each founder. Record sex, birth day or approximate birth year, occult type, generation, parents and household. You can add a portrait now or give every life stage its own portrait later.

5

Check your defaults

Open Rules & Data. Era rules, roll tables, death causes and historical events are already supplied. Edit only the parts your version of the challenge changes. Use Rules Health to identify missing dice, duplicate obligations or incomplete coverage.

6

Open Today

Today is the play screen. It gathers everything due now—rolls, deaths, pregnancies, illnesses and active historical events—without requiring you to visit every ledger.

Good to know

Automatic rolls never need to be created before the challenge’s configured start date. Changing the calendar later recalculates future obligations, so make a backup first if the save is already underway.

MOVING EXISTING RECORDS

Coming from a spreadsheet

When you know exact days

Use Global Day for births, marriages, pregnancies and deaths. Exact Global Days produce the most accurate due dates and automated rolls.

When you only know a year

Use the historical birth-year field on the Sim form. The tracker stores it as an approximate date instead of making you calculate a Global Day.

Recommended order

  1. Households
  2. Parents and founders
  3. Children
  4. Marriages and other relationships
  5. Pregnancies, illnesses and notes
02

WHILE YOU PLAY

Your daily routine

  1. Open Today.Confirm the displayed Global Day, historical year and Sims weekday. Use the task filters when you only want rolls, events, illnesses, pregnancies or deaths.
  2. Review what is due.Active events provide context; scheduled deaths tell you who must die in game; pregnancy and illness panels show anything that needs attention.
  3. Complete each roll.Use the illustrated native die or type the result from a physical die. The tracker selects the correct die, determines the outcome and saves it immediately.
  4. Resolve detected changes.Open Automation Inbox. Verify names, parents, dates, times, partners, babies, illnesses and deaths before accepting them.
  5. Advance the day.Move forward one day or skip seven days from Today. If Clock Sync is connected, in-game calendar changes advance the tracker without rewinding it when an older game save is loaded.
  6. Add story details.Write anything the game cannot detect in Notes or add a narrated entry on Storyline.
Before confirming a death

If an exact date or in-game time has already been recorded, confirmation preserves it. A failed lethal roll can move an unconfirmed scheduled death earlier, but never later.

04

DICE & CONSEQUENCES

Understand automatic rolls

Lifecycle rolls

Birth, aging, maternal, marriage and pregnancy-count obligations are generated from the active era tables. New babies receive their own future schedule after they are added.

Historical-event rolls

Event rolls are generated only for living Sims who match the event’s date, scope and location. Global events apply to every eligible living Sim. Hidden events stop appearing and stop generating obligations.

Occult rolls

Use the sidebar switch to enable automatic occult rules. Detected occult types receive their applicable checks. Triggered werewolf discovery and hunt consequences schedule their own follow-ups.

What happens after I enter a result?

The tracker records the actual number and calculates the matching rule outcome. Nonlethal results remain part of the roll history. A failed lethal Sim roll schedules a fitting death date and cause; event deaths use a cause connected to that event. You can reopen a mistaken roll while its automatic death remains unconfirmed.

Every completed result appears in Today’s result summary and remains available in Rolls. The Dice Audit records native-die results so their distribution can be reviewed.

Where do I edit dice, bad results and rules?

Use Rules & Data. Defaults are seeded automatically but remain editable per save. Keep a source or explanation in the notes field when you change a historical table.

05

OPTIONAL AUTOMATION

Connect The Sims 4 with Clock Sync

  1. 1
    Open Game Clock.

    Select the correct tracker save before creating the link.

  2. 2
    Download the private configured kit.

    This creates a new private token. Replacing it disables that save’s older Clock Sync configuration.

  3. 3
    Extract and install the ZIP.

    Open the included SeveralUDOClockSync folder and run Install or Update SeveralUDO Clock Sync.bat. It backs up the previous install and checks for exact-name duplicate Script Mods.

  4. 4
    Enable Script Mods in The Sims 4.

    Restart the game after installing or replacing the .ts4script file.

  5. 5
    Test, then start the relay.

    Run Test SeveralUDO Clock Sync.bat once, then double-click Start SeveralUDO Clock Relay.bat. A hidden window is normal; starting it twice is safe.

  6. 6
    Load a household in Live Mode.

    Let game time move or change lots. Refresh Game Clock until the last game day and time appear.

  7. 7
    Review the Automation Inbox.

    Clock Sync detects changes, but family-changing details stay reviewable so you can correct them before acceptance.

Keep the private kit private

Never share config.json, its sync token, a configured ZIP, or files from report_queue. Share the unconfigured complete kit instead.

Open Game Clock
What Clock Sync can detect

Supported reports can include game day and time down to the second; Sims save-slot identity; all exposed played households and their population; households and funds; new or missing Sims; age stage and progress; pregnancy stage, labor and birth counts; parents, children, siblings, grandparents and grandchildren; detailed relationship states and endings; deaths and resurrections; illness and recovery; careers, school and degrees; occult rank and powers; aspirations, lifestyles, fears, traits, skills, milestones, character values and preferences. Stable tuning IDs accompany readable labels when available. On compatible game builds, it can also import a small life-stage portrait.

Healthcare Redux is optional. When present, active disease buffs and diagnosed traits—such as influenza, pneumonia, malaria, meningitis and tuberculosis—are detected without importing or depending on the mod. Immunity, vaccines, medication and recent-illness markers are ignored. When Healthcare Redux is absent, Clock Sync continues normally.

Reports are checksummed, ordered, queued offline, and sent as small deltas after a complete baseline. The Game Clock page shows the paired save slot, last sequence, delivery continuity, and exposed telemetry modules.

What Clock Sync never does

It does not edit the Sims 4 save, control your Sims, install packs or approve uncertain family changes without review. The tracker also never automatically rewinds when you load an older game save.

PROTECT THE CHRONICLE

Backups, sharing and editions

Before large changes

Open Saves & Backups before imports, calendar changes or bulk edits. Create a snapshot or download an export that can be kept away from the tracker.

Hosted workspaces

Each signed-in workspace is private. Use Account & Sharing to invite someone intentionally. A workspace code should be treated like a password.

Desktop and hosted editions

The desktop edition keeps a local database. The hosted edition uses the online workspace. They do not continuously mirror each other; use Sync when you intentionally transfer changes.

08

WHEN SOMETHING LOOKS WRONG

Quick troubleshooting

A roll is missing

Confirm the Sim is alive, has a usable birth date, and the due date is not before the challenge start. Check that the relevant automatic-roll setting and era rule are active. Event rolls also require matching location and scope. Then open Rules Health.

A completed item is still on Today

Refresh Today and confirm the result was saved. Use Rules Health to repair duplicate obligations. Archived or hidden historical events should no longer produce visible rolls.

Clock Sync says Waiting

Run the included self-test, confirm the private config.json is beside the other files, start the relay, enter Live Mode and let time advance. If files remain in report_queue, open relay_health.json for the latest connection state. A replaced private kit requires its new configuration.

A detected change is wrong

Do not accept it yet. Automation Inbox lets you verify or correct the Sim, parents, partner, dates, exact time, illness, death cause and number of babies. Dismissing a detection remembers that decision so it does not return every day.

The tracker feels slow or has duplicates

Use filters instead of loading an entire ledger, archive unused records and run the duplicate repairs in Rules Health. If the hosted tracker reports a database or deployment error, wait for the service to recover before repeatedly submitting the same form.

AI marriage portraits do not generate

Manual marriage-photo upload always works. AI generation additionally requires the app owner to configure an OpenAI API key with available API credits.
