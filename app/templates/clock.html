DETAILED INSTALLATION

Install Clock Sync on Windows

  1. Close The Sims 4 before installing or replacing the .ts4script file.
  2. Download the ready-to-install private kit above and extract it. Open its SeveralUDOClockSync folder, then double-click Install or Update SeveralUDO Clock Sync.bat. It backs up the prior install and safely moves exact-name duplicate Script Mods into that backup.
  3. Confirm the file is no deeper than Mods → SeveralUDOClockSync → SeveralUDOClockSync.ts4script. Script Mods cannot be buried in extra folders.
  4. In The Sims 4, open Game Options → Other. Enable both Custom Content and Mods and Script Mods Allowed, then restart the game if either setting changed.
  5. Double-click Test SeveralUDO Clock Sync.bat. It checks the files, private config, writable queue and tracker receiver without advancing time. Then start Start SeveralUDO Clock Relay.bat.
  6. Start The Sims 4, load a household, enter Live Mode and let in-game time move briefly. Changing lots also triggers a new report.
  7. Return here. Receiver should say Active, and Last game day should no longer say Waiting.
  8. Open Automation Inbox to verify new Sims, pregnancies, illnesses, deaths, relationships and other detected details before accepting them.
Already installed? During an update, replace the Script Mod and relay files but keep your working config.json. Replace config.json only when connecting a different tracker save or repairing a private link.

Normal daily use

  1. Start the relay.
  2. Open The Sims 4 and play in Live Mode.

Troubleshooting

Receiver still says Waiting

Start the BAT file, load a household in Live Mode and let time advance or change lots. Confirm config.json is beside the Script Mod. Refresh this page after the report.

The BAT file flashes and disappears

That is expected. The relay runs in a hidden PowerShell window. A built-in mutex prevents duplicate relay processes.

Reports are waiting in report_queue

Open relay_health.json or last_result.json. The relay keeps every report in order while offline and removes a report only after the tracker acknowledges it. Fix the connection and leave the relay running; it resumes automatically.

The wrong Sims save was loaded

Clock Sync 2.2 rejects a different Sims save slot before changing the tracker. If you intentionally switched this tracker to that game save, use the protected reset below, return to Live Mode and let time move.

The mod is missing from the game's startup list

Enable Script Mods Allowed, keep the .ts4script no more than one folder beneath Mods, remove duplicate old copies and restart The Sims 4. If needed, close the game and remove localthumbcache.package.

The PowerShell relay or BAT file is missing

Open and extract the SeveralUDOClockSync folder inside the ZIP. If Windows security filtered either command file, rename its matching .backup.txt recovery copy by removing only .backup.txt. The individual download buttons above are another safe fallback.

ModGuard or security software warns about networking

Clock Sync {{clock_sync_version}} writes locally inside the game. The separate PowerShell relay performs the HTTPS request. Use only files downloaded from this tracker and never approve differently named scripts or executables.
