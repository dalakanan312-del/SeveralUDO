Install the fully compatible bridge

Clock Sync 2.0.1 sends pregnancy counts and progress, traits, skill levels, milestones, career, education, illness detail, occult state, death, household, location, parent and relationship details for active and played households. It recognizes supported occult states without requiring every pack and safely ignores unavailable packs or optional health mods.

Download Clock Sync 2.0.1

  1. Close The Sims 4 before changing Script Mods.
  2. Replace SeveralUDOClockSync.ts4script in Documents → Electronic Arts → The Sims 4 → Mods → SeveralUDOClockSync. Keep your existing config.json and relay files.
  3. Enable Script Mods in The Sims 4, then restart the game.
  4. Create a private link above only if the current link is missing or needs to be replaced.
  5. Start the local tracker and relay before the game when using the desktop edition.
  6. Open a household and let live mode run briefly. The first successful report pairs the current game day with Global Day {{save.global_day}}.
  7. Review detected details in Automation Inbox before accepting them.

The game can still report if it was opened before the relay; start the relay, then change lots or let live mode advance to trigger another report.
