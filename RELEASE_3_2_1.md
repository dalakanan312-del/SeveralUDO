# Decades Tracker 3.2.1

Version 3.2.1 focuses on everyday play-session speed and clarity.

- Sim menus sort by numeric Sim ID with the highest number first.
- An optional recent-first mode keeps recently handled Sims above the remaining
  numerically sorted list.
- Sidebar destinations are grouped into Play, Family, World, Reference, and
  Manage sections with one-click navigation.
- Today, Rolls, Pregnancies, Events, and Illnesses show live workload badges.
- Today supports due/overdue filters, category filters, remembered card density,
  and remembered preview choices.
- Upcoming work can be viewed as Next day, Next 7 days, or Later.
- Selected and death-day portraits use cached compressed WebP thumbnails;
  original Sim portraits remain unchanged.
- Rolls, pregnancy outcomes, and illness recovery are available directly from
  Today.
- The most recent reversible Today action offers Undo.
- The historical visual system has refreshed navigation, active states, cards,
  and page headers.

No database migration is required and existing saves remain compatible.
