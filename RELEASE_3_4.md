# Tracker 3.4.0

## Automatic pregnancy discovery

- Clock Sync 1.4.0 detects pregnancy-state changes directly from the active Sims 4 household.
- A new tracker popup offers to add each newly discovered pregnancy without creating duplicates on repeated reports.
- The popup preselects the pregnant Sim and other parent by name when matching tracker profiles exist.
- Pregnancy progress, configured pregnancy length, expected babies, and the current Global Day provide editable conception and due-day estimates.
- Accepting the popup creates the pregnancy and refreshes its automatic maternal-roll schedule.
- Each Sim can be detected again after a pregnancy ends and a later pregnancy begins.
- Pregnancy detection adds no in-game networking; reports continue through the local JSON queue and secure Windows relay.
