DECADES TRACKER — OFFLINE SQLITE EDITION

1. Extract the entire ZIP to a permanent folder.
2. Install Python 3 from python.org if it is not already installed.
3. Double-click "Start Decades Tracker Local.bat".
4. The first launch installs the private local runtime and opens the tracker.

Your data is stored under local_data\saves and never leaves this computer.
The included starter save is imported automatically on first launch.

RETURNING TO THE BROWSER / NEON

1. In the local tracker, open Saves > Manage.
2. Download "Export shareable save".
3. Open the browser tracker and choose Saves > Import.
4. Upload that .decades-save file. It becomes a new independent Neon save.
5. Confirm the imported save before deleting either copy.

The local edition does not use Google login, Railway, Neon, or automatic game
clock sync. Keep regular .decades-save backups, especially before updating.
