DECADES TRACKER v1.0 — SHORT USER GUIDE
=======================================

TODAY
-----
Use Current Global Day as the main play-time input.

The Today page automatically shows:
- historical year
- challenge day within the four-day year
- Sim weekday
- historical date range
- rolls due
- pregnancies due
- active historical events
- upcoming automatic rolls

SIMS
----
Directory:
Browse profiles by name, status, or generation.

Add Sim:
A short form for normal gameplay. Birth Global Day defaults to the current
Global Day. Generation can calculate from recorded parents.

Edit Sim:
Edit the profile in smaller sections instead of one giant form.

Family & Relationships:
Manage parents, children, and partnerships from one focal Sim.

PHOTOS
------
PNG, JPG/JPEG, and WEBP portraits can be attached to Sims.

Photos are stored inside the save database, so they are included in save exports
and backups.

FAMILY TREE
-----------
Choose a focal Sim and select:
- Family
- Ancestors
- Descendants

Depth controls how far the tree expands.

Solid arrows:
parent -> child

Dashed lines:
marriage / partnership

Uploaded portraits can appear directly on the tree.

SAVES
-----
Use the selector at the top of the sidebar to change worlds.

The Saves page can:
- create a blank save
- duplicate a save
- rename a save
- export a shareable save
- import a shared save
- delete a save

A blank save can start in a completely different historical period.

ROLLS
-----
Automatic scheduling creates rule-driven rolls when they become due.

Future obligations are previewed rather than inserted early.

Configure historical/species-specific roll tables under:
  Rules & Data -> Roll Tables

TIMELINE
--------
Timeline combines dated activity from:
- births
- deaths
- relationships
- pregnancy records
- households
- events
- event effects
- optional rolls

Use the filters and range slider to narrow the view.

STATISTICS
----------
Statistics are calculated from the active save only.

Switching saves switches the entire statistical dataset as well.
