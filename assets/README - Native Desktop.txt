DECADES TRACKER 4.5.7 - NATIVE WINDOWS EDITION
================================================

1. Extract the complete Decades Tracker folder before opening it.
2. Double-click Decades Tracker.exe. It opens in its own Windows application window.
3. Keep the _internal folder beside the executable. The application needs those files.

YOUR DATA
- Local saves are stored privately under Local AppData\DecadesTracker\decades-v4.db.
- Replacing or uninstalling the program files does not remove that database.
- Use Saves & Backups inside the tracker for portable backups.
- Hosted Neon synchronization remains optional and must be configured from Sync.

CLOCK SYNC
- Open Game Clock inside the tracker to download the current Clock Sync kit.
- The local tracker and its Clock Sync relay must be running while you play.

WINDOW REQUIREMENT
- This edition uses Microsoft's automatically updated WebView2 Runtime.
- Windows 11 includes it, and it is present on most supported Windows 10 computers.
- If the application cannot create its window, install WebView2 from Microsoft's official page:
  https://developer.microsoft.com/microsoft-edge/webview2/

TROUBLESHOOTING
- Startup diagnostics are written to Local AppData\DecadesTracker\startup-error.log.
- Do not disable antivirus protection to run an unfamiliar copy.
- Only use downloads published by SeveralUDO and verify the provided SHA-256 checksum.
