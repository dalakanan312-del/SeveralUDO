# 4.6.30 — One growing decade group portrait

- History → Decade Snapshots adds eligible Sims to the same year's image, with a roster, optional names, background color, and download.
- Infinite Decades branches share the album. Restoring a branch does not rewind or hide the shared images; repeated scans do not duplicate a Sim.
- A plain white background, large serif year, closely arranged cutouts, and child/adult scaling replace the tiled layout. Existing source poses and image crops are preserved; imported non-transparent photos retain their backgrounds.
- Every included appearance is stored separately and frozen. Later deaths, age changes, and updated profile pictures do not change an old snapshot.
- Converting a legacy collage keeps a full save backup and its original image. Historical Tray photos are matched against the original tiles, not blindly replaced with today's photos. If a source is unavailable, the original tile is preserved.
- Each dynasty branch gets a single milestone reminder. Prior dismissals remain resolved on their original branch.

Verification: 45 focused tests cover identity, historical eligibility, frozen appearances, preserved legacy layouts, historical image matching, shared branch restores, large groups, persistent reminders, and the page/form/image endpoints.
