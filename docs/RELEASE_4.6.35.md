# 4.6.35 — Whole dynasty register

Infinite Decades now shows a compact, expandable table inspired by Sheet26:
split/play year, branch, name, sex, generation, birth date, birthplace, recorded
children, age and living/deceased status. Main, already-played, waiting, paused
and completed branches appear together; this is separate from the branch picker.

Each tracked Sim appears once using their stable ID, including frozen relatives,
the deceased and people excluded from the diagram. Same-name Sims stay separate.
Starting-world checkpoints do not duplicate the founders. Empty completed branch
history remains accessible. Archived non-frozen records stay archived.

Ages are calculated at the preserved date or death, using the save's year length.
Unknown data stays unknown. Searching, expanding and viewing never changes the
active branch, Global Day, game connection, records or checkpoints.

The family tree links directly to the complete register. The supplied screenshot
was used as a layout reference, not imported as new Sim records.
