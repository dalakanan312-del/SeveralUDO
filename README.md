# Decades Tracker v1.0

This branch restores the latest verified intact local build from August 10, 2026, before the corrupted v2.0 GitHub packaging.

## Quick start

1. Download or clone this repository on 64-bit Windows 10 or Windows 11.
2. Double-click `Launch Decades Tracker.bat`.
3. On first launch, the launcher downloads a private Python runtime and installs the required packages.
4. The tracker opens in your browser.

The first launch requires an internet connection. Later launches reuse the private runtime.

## Data safety

User databases, save indexes, private runtimes, credentials, and environment files are intentionally excluded from this repository. Keep regular backups using the tracker's export tools.

See `README_FIRST.txt` and `USER_GUIDE.txt` for complete usage instructions.
