DECADES TRACKER — CLEAN SHAREABLE WINDOWS COPY
===============================================

This copy contains NO personal Sims or personal save data.

REQUIREMENTS
------------
- Windows 10 or Windows 11, 64-bit
- internet connection for the FIRST launch only

The recipient does NOT need to install Python manually and does NOT need
administrator rights.

HOW TO START
------------
1. Extract the entire folder somewhere writable, such as Documents or Desktop.
2. Double-click:
      Launch Decades Tracker.bat
3. On first launch, wait while the app automatically downloads its private
   Python runtime and dependencies.
4. The tracker opens in the default web browser.
5. Keep the launcher window open while using the tracker.

Later launches reuse the private runtime and are much faster.

WHAT IS INCLUDED
----------------
The clean app includes:
- multiple independent saves
- different calendar starting years per save
- Global-Day-first tracking
- Sim profiles and portraits
- easier family/relationship editing
- family tree
- pregnancies and outcomes
- automatic rule-driven rolls
- era/year/species roll tables
- households
- historical events
- detailed statistics
- unified timeline
- save export/import

SHARING WORLDS
--------------
A player can export one save from:
  Saves -> Manage saves -> Export shareable save

This creates a:
  .decades-save

Send that ONE file to another Decades Tracker user.

The recipient imports it from:
  Saves -> Import a shared save

The shared save includes the entire selected world, including its photos and
save-specific rules. It does not include the sender's other saves.

DATA LOCATION
-------------
Each save is stored in its own SQLite database inside the app's "saves" folder.
Portraits are stored inside that save database.

For normal sharing, use the .decades-save export instead of manually copying
files from the saves folder.

SIM WEEKDAY
-----------
The Today page now shows the Sim weekday automatically. Global Day 1 is Sunday, then the seven-day week repeats continuously.
